# スティック操作試作（通常版から独立）

公開先: https://ob198-cpu.github.io/rubimon/stick/

- 見回す: キューブを直接ドラッグする。視点だけ動き、手数は消費しない。スティックは列回転専用。
- 列を回す: キューブのパネルをタップしてから、スティックを倒す。水色のガイドを確認して離すと1手回転。
- 中心に戻して離す／操作がキャンセルされた場合は回転しない。
- 攻撃や補充の実行中は列操作を受け付けない。スキルの4パネル選択は維持。
- ヒントは対象の列を表示し、専用の確認ボタンで回転。
- キーボード: スティックにフォーカスし、矢印キーで操作。

元のアセットとロジックをこのフォルダーに複製。通常版のファイルは変更しない。
編成・所持キャラ・振動設定の保存キーも通常版と分離。
戦闘・補充・属性・キャラのルールは複製元と同じ。
これは画面上のアナログスティックの試作であり、特定製品の素材は使用していない。

検証: `node stick/stick.test.cjs`。Android LINE実機の動作は未確認。
