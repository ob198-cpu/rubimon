# ルビモン

2Dの円図と3Dキューブを連動させる属性パズルRPGの試作です。

## 遊び方

- 矢印ボタンで列を回転。1手ごとに自動で攻撃判定します。
- 同じ属性を1列そろえると攻撃、1面そろえると技が発動します。
- 通常は3手ごとに敵が行動します。
- 仲間5体の技や編成を変更できます。
- 敵の妨害は初期状態ではOFF。設定から切り替えられます。

## 実行

GitHub Pagesで公開する静的HTML/CSS/JavaScriptのゲームです。課金・ユーザー登録・サーバー保存は実装されていません。
